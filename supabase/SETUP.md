# راه‌اندازی چت واقعی Arshagon

این پروژه فعلاً رابط کاربری دارد. برای ارسال پیام بین دو دستگاه، به یک پروژه Supabase نیاز است.

## ۱) ساخت پروژه
1. وارد https://supabase.com شوید و یک پروژه جدید بسازید.
2. از بخش **SQL Editor**، فایل `schema.sql` همین پوشه را باز کنید و محتوایش را اجرا کنید.
3. از **Project Settings → API** این دو مقدار را بردارید:
   - Project URL
   - Publishable key (یا anon/public key قدیمی)

**هرگز Service Role key را در سایت یا چت نفرستید.** این کلید محرمانه است.

## ۲) نکته امنیتی مهم
این SQL فقط برای نمونه اولیه است: سیاست‌ها اجازه خواندن و نوشتن عمومی می‌دهند و رمز اتاق را به‌صورت امن اعتبارسنجی نمی‌کنند. تا زمانی که اعتبارسنجی رمز از طریق سرور/Edge Function اضافه نشده، اطلاعات خصوصی یا حساس در اتاق‌ها نفرستید. کد اتاق را تصادفی و غیرقابل حدس نگه دارید.

## ۳) مرحله بعد
بعد از ساخت پروژه، فقط **Project URL** و **Publishable/anon key** را برای اتصال فرانت‌اند لازم داریم. Service Role key لازم نیست و نباید افشا شود.
